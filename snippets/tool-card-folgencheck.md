# Toolkarte: Folgencheck

Titel:
Folgencheck durchführen

Nutzerfrage:
Was kann eine Aussage, Maßnahme, ein Produkt oder eine Entscheidung auslösen - bevor Schaden eingetreten ist?

Heutige Blindstelle:
Oft wird nur geprüft, ob etwas stimmt, erlaubt oder finanzierbar ist. Wirkungspotenziale, Nebenwirkungen und Wirkungsräume bleiben unsichtbar.

Was das Tool zeigt:
Der Folgencheck macht Wirkstoffe, Wirkungspfade, Wirkungsräume, Wirkungsempfänger, Datenlücken und Schutzgrenzen sichtbar.

Ergebnis bedeutet:
Das Ergebnis ist keine finale Bewertung. Es ist eine strukturierte Frühwarnung und Entscheidungshilfe.

# Präsentationsvorlagen

Dieser Ordner enthält die verbindliche Basis für Präsentationen der Akademie für Wirkungsökonomie.

## Master-Template

`wirkungsoekonomie-akademie-master-template.pptx`

Verwendung:

- als Ausgangsdatei für alle neuen Akademie-Vorlesungen und Präsentationscharts
- Folien aus dem Template duplizieren und Inhalte ersetzen
- Brand-System beibehalten: Navy, Ivory, Green, Gold, Coral; Serif-Headlines; ruhige Diagramm- und Tabellenlogik
- keine dekorativen Stockbilder oder generischen ESG-Visuals verwenden
- je Folie eine klare These und ein dominantes Beweis- oder Orientierungsobjekt

## Enthaltene Layouts

- Cover
- Layoutbibliothek
- Brand-System
- Kapiteltrenner
- Agenda / Vorlesungsbogen
- Konzeptfolie
- Modellfolie
- Rückkopplungsfolie
- Vergleichsmatrix
- Datenchart
- Fallstudie
- Zitat / Kerngedanke
- Quellen / Appendix

## Arbeitsregel

Neue Präsentationen können zusätzlich unter `dokumente/` oder einem vorlesungsspezifischen Zielordner abgelegt werden. Die wiederverwendbare Grundlage bleibt dieses Template in `templates/presentations/`.

Reverse Merit Order

Reverse Merit Order stellt sicher, dass das schwächste kritische Wirkungsfeld die Bewertung begrenzt.

Auf einen Blick

Die Reverse Merit Order bedeutet: Das schwächste kritische Wirkungsfeld begrenzt die Gesamtbewertung.

Definition

Was bedeutet der Begriff?

Kurzdefinition: Reverse Merit Order stellt sicher, dass das schwächste kritische Wirkungsfeld die Bewertung begrenzt.

Erklärung: Die Reverse Merit Order ist eine Schutzlogik gegen Schönrechnung. Sie macht kritische Schäden entscheidungsrelevant und verbindet Netto-Wirkung mit Nicht-Kompensation.

WÖk-Bezug: Nicht als bloße Rechenregel ohne Schutzlogik verwenden.

Grenze / Status: Nicht als bloße Rechenregel ohne Schutzlogik verwenden.

Schreibweisen: Nichtkompensationsprinzip, Minimum-Operator, Engpasslogik

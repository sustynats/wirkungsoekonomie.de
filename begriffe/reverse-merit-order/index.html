Bewertungsbegriff

Reverse Merit Order

Reverse Merit Order stellt sicher, dass das schwächste kritische Wirkungsfeld die Bewertung begrenzt.

Version 1.0published
Themenseite öffnenAlle BegriffeWebsite durchsuchen

Auf einen Blick

Die Reverse Merit Order bedeutet: Das schwächste kritische Wirkungsfeld begrenzt die Gesamtbewertung.

Definition

Was bedeutet der Begriff?

Die Reverse Merit Order ist eine Schutzlogik gegen Schönrechnung. Sie macht kritische Schäden entscheidungsrelevant und verbindet Netto-Wirkung mit Nicht-Kompensation.

Wirkungsökonomie

Warum ist das wichtig?

Reverse Merit Order als Nichtkompensationslogik einsetzen.

Verwendung

So wird der Begriff genutzt

Nicht als bloße Rechenregel ohne Schutzlogik verwenden.

Abgrenzung

Nicht verwechseln mit

  • Merit Order
  • Durchschnittsscore

Lernpfad zu Reverse Merit Order

Warum wichtig?

Was macht der Begriff sichtbar?

Sie schützt vor dem Schönrechnen schwerer Schäden durch gute Werte an anderer Stelle.

Abgrenzung

Was es nicht bedeutet

Sie ist kein einfacher Durchschnitt und keine Strafliste.

Beispiel

So wird es konkret

Gute Klimawerte heben schwere Kinderrechtsverletzungen in einer Lieferkette nicht auf.

Missverständnisse

Worauf achten?

  • Nicht jede Schwäche blockiert alles.
  • Entscheidend sind definierte Wirkungsgrenzen.

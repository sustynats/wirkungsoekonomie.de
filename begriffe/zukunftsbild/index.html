Zukunftsbild

Ein Zukunftsbild ist eine orientierende Vorstellung davon, wohin sich ein System, eine Gesellschaft oder ein Handlungsfeld entwickeln kann.

WÖk-PräzisierungsbegriffStand / Version 1.0
Alle BegriffeWebsite durchsuchen

Auf einen Blick

Ein Zukunftsbild ist eine orientierende Vorstellung davon, wohin sich ein System, eine Gesellschaft oder ein Handlungsfeld entwickeln kann.

Definition

Was bedeutet der Begriff?

Zukunftsbilder geben Veränderung eine Richtung. Sie können abstrakte Risiken in gestaltbare Handlungsräume übersetzen, wenn sie glaubwürdig, anschlussfähig und realistisch bleiben.

Wirkungsökonomie

Warum ist das wichtig?

Zukunftsbilder sind konstruktive Wirkstoffe. Sie können Dissonanz reduzieren, Selbstwirksamkeit erhöhen und Transformationswirkung vorbereiten, wenn sie glaubwürdig, anschlussfähig und realistisch sind.

Verwendung

So wird der Begriff genutzt

Als normalen menschlichen oder systemischen Verarbeitungsmechanismus beschreiben, nicht als Abwertung von Personen.

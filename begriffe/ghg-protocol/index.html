GHG Protocol

Das GHG Protocol ist ein international verbreiteter Standardrahmen zur Bilanzierung von Treibhausgasemissionen.

Auf einen Blick

Das GHG Protocol ist ein international verbreiteter Standardrahmen zur Bilanzierung von Treibhausgasemissionen.

Definition

Was bedeutet der Begriff?

Die WÖk nutzt GHG-Daten als Klimadatenbasis, ergänzt sie aber um soziale, ökologische und demokratische Wirkung sowie Rückkopplung.

Wirkungsökonomie

Warum ist das wichtig?

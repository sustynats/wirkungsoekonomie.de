Warum Migration in diesem Modell so zentral wird#

Aktuelle Fassung

Diese Lesefassung ist im Bibliotheksregister als aktueller Dokumentstand eingeordnet. Dokumenteintrag

Im September 2026 hat Fukuyama diesen Zusammenhang ungewöhnlich direkt auf die aktuelle Lage in Europa bezogen. Im Gespräch mit Walter Isaacson nannte er Migration als eines der großen Themen der nationalistischen Rechten. Menschen glaubten, ihre Kultur, ihre Werte und eine vertraute Form gemeinsamer Identität zu verlieren. In diesem Zusammenhang verwies er ausdrücklich auch auf die AfD in Deutschland. [3] Wichtig ist die Formulierung: Fukuyama beschreibt eine Wahrnehmung kulturellen Verlusts. Daraus folgt noch nicht, dass eine Gesellschaft objektiv ihre Kultur „verliert“, ebenso wenig, dass alle migrationskritischen Einstellungen aus derselben Motivation entstehen. Eine politische Einstellung kann aus sehr unterschiedlichen Erfahrungen, Wertvorstellungen und Interessen hervorgehen.

Sein Modell erklärt vielmehr, warum Migration eine andere emotionale Qualität annehmen kann als viele andere Politikfelder. Eine Steuerreform verändert möglicherweise das verfügbare Einkommen. Migration kann zusätzlich als Frage gelesen werden, wer künftig zum „Wir“ gehört, welche Normen gelten und ob die vertraute gesellschaftliche Ordnung fortbesteht. Sobald ein Thema mit Identität verbunden ist, wird aus einer Sachfrage leicht eine Zugehörigkeitsfrage.

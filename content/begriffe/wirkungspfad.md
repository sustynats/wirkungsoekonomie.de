# Wirkungspfad

## Kurzdefinition

Ein Wirkungspfad beschreibt, wie aus einem Wirkstoff über bestimmte Mechanismen Wirkung entstehen kann.

## Erklärung

Der Wirkungspfad verbindet Gegenstand, Wirkstoff, Wirkungsempfänger, Wirkungsraum und mögliche Zustandsveränderung. Er hilft, Wirkung nicht nur zu behaupten, sondern nachvollziehbar zu erklären.

## Beispiele

- Preis -> Kaufentscheidung -> Nachfrage -> Produktionsstruktur -> Lieferkettenwirkung.
- Frame -> Emotion -> Zugehörigkeit -> politisches Verhalten -> demokratische Stabilität.
- Algorithmus -> Reichweite -> Aufmerksamkeit -> Normalisierung -> Diskursqualität.
- Automatisierung -> Lohnsumme -> Sozialbeiträge -> Finanzierungslücke -> Sicherungssystem.

## Anwendung

Im Folgencheck ist der Wirkungspfad der Schritt, der aus einem möglichen Wirkstoff eine plausible Wirkungshypothese macht.

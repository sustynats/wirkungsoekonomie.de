# Kontrollierte Word-Quellen

Die beiden redaktionellen Word-Originale werden außerhalb dieses Website-Repositorys vorgehalten:

- `Wirkungswahl-Kompass_Methodik_Content_UX-Paket_v1.0.docx`
- `Wirkungswahl-Kompass_Redaktionelles_Inhaltspaket_v1.0.docx`

Sie dürfen nicht in das Website-Repository kopiert werden. Die Release-Prüfung behandelt alle dort abgelegten Download-Dateien als potenziell öffentlich. Für eine Content-Aktualisierung werden die Originale als explizite Eingabepfade an `parse_editorial.py` übergeben; veröffentlicht wird ausschließlich der geprüfte JSON-Datensatz.

# Source Assets

Dieser Ordner ist der Importbereich für Originaldokumente der WÖk-Online-Referenz.

## Regeln

- Originaldateien bleiben unverändert.
- Importierte Webfassungen erhalten eigene Versionen.
- Fehlende Dokumente werden nicht improvisiert, sondern in `docs/IMPORT_REVIEW_NOTES.md` und `public/data/asset-inventory.json` dokumentiert.
- Große Import- und PDF-Konvertierungsläufe müssen nicht im GitHub-Pages-Deploy laufen.

## Erwartete Struktur

```text
source-assets/
  originals/
```

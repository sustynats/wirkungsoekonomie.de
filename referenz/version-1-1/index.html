Release Candidate

Version 1.1 - Begriffliche Präzisierung und Referenzordnung

Release Candidate der Wirkungsökonomie auf Grundlage des Führenden Begriffsleitfadens, Stand 21. Mai 2026.

Terminologiebasis

Diese Online-Referenz folgt dem Führenden Begriffsleitfaden der Wirkungsökonomie, Version 1.0, Stand 21. Mai 2026. Wo Zielgrößen gemeint sind, spricht die aktuelle Fassung von positiver Netto-Wirkung für Mensch, Planet und Demokratie.

Status

Version 1.1 ist eine begriffliche, methodische und dokumentarische Aktualisierung der Wirkungsökonomie. Sie ist kein geltendes Recht und keine amtliche Methodik.

Warum Version 1.1?

Diese Version präzisiert zentrale Begriffe, ordnet ältere Projektdateien ein und macht Quellen, offene Prüfungen, Changelog und Release-Dokumentation sichtbar.

Terminologiebasis

Führender Begriffsleitfaden der Wirkungsökonomie, Version 1.0, Stand 21. Mai 2026.

Wichtigste Änderungen

  • Wirkung wird neutral definiert.
  • Zielgröße ist positive Netto-Wirkung für Mensch, Planet und Demokratie.
  • Wirkungspotenzial wird von Wirkung getrennt.
  • Wirkstoff wird als Analogie eingeordnet.
  • SDG+ wird als WÖk-Erweiterung erklärt, nicht als offizielle UN-Kategorie.
  • NWI und T-SROI werden getrennt.
  • FinalScore, NWI, T-SROI und WIF werden eingeordnet.
  • WStG wird als Rahmengesetz verstanden; WUStG und WEstG werden als Module eingeordnet.
  • Personenbewertung, Gesinnungsbewertung, Lebensstilbewertung und Social Credit werden ausgeschlossen.
  • Fehlbarkeit, Pilotierung, Evaluation und Reversibilität werden hervorgehoben.
  • Glossar, Hoverdefinitionen, Quellenregister, Referenz-Metadaten und Changelog wurden verbessert.

Was Version 1.1 nicht ist

  • kein geltendes Recht
  • keine verbindlichen Steuersätze
  • keine finale juristische Prüfung
  • keine amtliche Methodik
  • keine Finanzierungszusage
  • keine Personenbewertung
  • kein Social-Credit-System

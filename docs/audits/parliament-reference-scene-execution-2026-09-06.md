## Enforcement and retention

The new read-only candidate checker binds the complete seven-item set to the
unchanged contract, approved source descriptor, exact provider/model, prompt
hashes, immutable source commit and common reference bytes. Every QA row binds
the actual asset hash. Missing/duplicate rows, changed Fach path IDs, missing
OPEN guards or a forged aggregate PASS fail. Optional `--assets` verifies all
actual file hashes, dimensions, lengths and media types.

Normal invocation returns failure for this rejected set. CI uses the explicit
`--expect-rejected` assertion to prove truthful rejection, not publication
readiness. Mutation tests run without a generation request. Rejected original
bytes cannot be copied into the public scenario tree under another filename.

The 53,127,479-byte candidate archive remains in the GitHub Actions audit artifact
and original private Oracle generation journals. The artifact has a 30-day
retention period; the committed metadata/QA survives independently. No rejected
image bytes enter Git, GitHub Pages or the Parliament runtime. Existing six
Program-v2 and six Case-v1 signed-off assets remain current and untouched.

## Roter Faden

Die Website wurde stärker entlang dieses Lernbogens ausgerichtet:

1. Was ist das Problem?
2. Was ist Wirkungsökonomie?
3. Woran wird Wirkung gemessen?
4. Welche Daten gibt es bereits?
5. Wie wird daraus eine Bewertung?
6. Wie wird daraus eine Wirkungsklasse?
7. Wie wirkt diese Bewertung zurück in Preise, Steuern, Kapital und Entscheidungen?
8. Wo kann man es erleben, vertiefen und anwenden?

## Fachbegriffe nach hinten verschoben

Auf Einstiegsflächen wurden Fachbegriffe reduziert oder später eingeordnet:

- WÖk-ID steht auf der Modellseite nicht mehr am Anfang, sondern im Governance-Baustein.
- T-SROI bleibt ein Vertiefungsinstrument und wird nicht als Einstieg erklärt.
- Reverse Merit Order wird zuerst als Schutzregel erklärt: Das schwächste Feld entscheidet.
- NWI wird nach Scorecard und Netto-Wirkung eingeführt.
- Scorecards werden zuerst als Wirkungsbewertung erklärt.

## Ergänzte Prozesslogik

Neu sichtbar gemacht wurde die Prozesskette:

Normativer Rahmen -> SDGs / SDG+ -> Datenquellen -> Indikatoren -> Scorecard -> Netto-Wirkung / NWI -> Schutzregel -> Wirkungsklasse -> Steuerklasse -> Steuersatz / Preis / Entscheidung -> Lernen und Evaluation

Diese Logik wurde ergänzt auf:

- `/modell.html` mit der Sektion `Vom Maßstab zur Entscheidung`
- `/workflow.html` als eigener zentraler Prozessseite
- `/index.html` über die Karte `Von Daten zum Steuersatz`
- `/anwendungen.html` über die Anwendungslogik
- `/erleben.html` über den Workflow des Produkt-Simulators
- `/downloads.html` über den Abschnitt `Zum operativen Einstieg`
- `/ueber.html` und `/natalie-weber.html` über Links zur Workflow-Seite

## Offene Punkte

- Dossierseiten können später stärker als vollständige Lernpfade ausgebaut werden.
- Anwendungen könnten je Feld noch tiefere Einzelabschnitte erhalten.
- Glossar-Hover ist bereits vorbereitet, sollte bei neuen Fachbegriffen weiter gepflegt werden.
- Eine spätere Detailseite zu Datenqualität, WÖk-ID und Wirkungsrat wäre sinnvoll.
- Eine spätere Detailseite zu Steuerklassen und politischer Festlegung von Steuersätzen wäre sinnvoll.

# Go 2 - Produktionsreihenfolge echte Detailkonzepte

**Version:** v1.0
**Stand:** 24.05.2026
**Autorin/Referenz:** Natalie Weber · Wirkungsökonomie
**Zweck:** Festlegung der Produktionsreihenfolge für die echten A-Fachdetailkonzepte aus der bereinigten Go-1-Matrix.

## Ergebnis

Aus der bereinigten A/B/C/D/E-Matrix werden **122 echte Fachdetailkonzepte** produziert.

Nicht enthalten in dieser Zahl:
- **21 C-Themen**: Methoden-, Tool- oder Referenzpapiere.
- **13 B-Themen**: Pflichtbausteine in allen Konzepten.
- **2 D-Themen**: Portal-/Übersichtsebene.
- **10 E-Themen**: Zusammenlegung, Umbenennung oder kein eigenständiges Papier.

## Produktionslogik

- Pro Produktionspaket maximal **3 echte Detailkonzepte**.
- Sehr komplexe Pakete können bei Bedarf in 1-2 Einzel-Gos aufgeteilt werden.
- Pakete sind bewusst **phase-rein**, damit keine Themen quer durcheinanderlaufen.
- Jedes A-Konzept wird im Referenzumfang erstellt: Kurzprofil, Executive Summary, Diagnose, Akteursgruppen, Wirkungsmechanik, Daten-/Indikatorenlogik, Steuer-/Fonds-/Anreizbezug, politische Anschlussfähigkeit, Toolbezug, Website-Integration und Fazit.
- Danach werden Dossier und Online-Volltext abgeleitet.

## Qualitätssicherung

Ein Dokument darf erst als „Detailkonzept“ gelten, wenn es den Referenzumfang erreicht. Kurztexte, Teaser, Portalintros, Toollisten und 2-Seiten-Skizzen sind keine Detailkonzepte.

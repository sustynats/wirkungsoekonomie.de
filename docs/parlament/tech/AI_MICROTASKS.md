# WÖK-KI Microtasks

WÖK-KI is an optional editorial helper, not a commentator or decision-maker.  Allowed calls have a fixed task type, minimal source snippets, fact fields, candidate options, WÖk reference IDs and strict JSON output.  Examples: bounded classification, candidate comparison, second-order candidates, evidence-conflict summary, diff hint, counterargument draft and plain-language draft.

It must not receive whole dossiers by default, extract trivial metadata, make a final normative boundary decision, publish, change a recommendation or create a rule.  Every result remains `AI_SUGGESTION` until a human uses it in a decision.

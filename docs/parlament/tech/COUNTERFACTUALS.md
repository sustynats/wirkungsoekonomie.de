# Counterfactuals

Ein Vorher-Nachher-Unterschied ist nicht automatisch eine zurechenbare Wirkung.
Jede quantitative Wirkungsbehauptung dokumentiert daher einen Gegenfaktumstyp:
`STATUS_QUO`, `TREND_CONTINUATION`, `CONTROL_GROUP`, `COMPARISON_REGION`,
`MODELLED_COUNTERFACTUAL`, `EXTERNAL_EVALUATION` oder `UNKNOWN`.

Bei `UNKNOWN` oder `UNRESOLVED` ist keine freigegebene starke quantitative
Kausalaussage möglich. Das System erzeugt stattdessen eine
`COUNTERFACTUAL_REVIEW` oder weist den Aspekt als nicht robust quantifizierbar
aus. Eine nicht gewählte politische Option ist stets `MODELLED`, `ESTIMATED`
oder `UNRESOLVED`, niemals beobachtet.

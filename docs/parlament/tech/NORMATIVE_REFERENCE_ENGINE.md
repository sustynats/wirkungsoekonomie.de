# Normative Reference Engine

**Entscheidung: REUSE.** Führend ist der SDG-/SDG+-Referenzrahmen v0.3 samt Onlinefassung; SDG+ wird als WÖk-Erweiterung ausgewiesen, nicht als UN-Kategorie. Master Items v1.3 liefert 621 WÖk-IDs und 28 Regeln.

Ein Mapping speichert Referenz-ID, Richtung (`STRENGTHENS`, `WEAKENS`, `UNCERTAIN`), Evidenzklasse und Begründung. Positive Netto-Wirkung ist eine Zielgröße; ohne vollständige Belege wird keine belastbare Empfehlung ausgegeben.

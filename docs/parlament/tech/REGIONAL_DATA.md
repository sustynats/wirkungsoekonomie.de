# Regional Data

**Entscheidung: REUSE + BUILD_NEW.** Der Bestand enthält Wahlkreiskontextdaten, aber keine belastbare AGS-/Kommune↔Wahlkreis-Zuordnung. Eine neue Schicht speichert `territorial_level`, `territorial_id`, `is_exact` und `is_proxy`.

Bis sie und eine lizenzgeklärte Kennzahl vorliegen, ist `DATA_GAP` der korrekte öffentliche Standard. Die abgeschaltete KWI-Quelle wird nicht als aktuelle Evidenz verwendet.

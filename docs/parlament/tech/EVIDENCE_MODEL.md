# Evidence Model

**Entscheidung: REUSE + EXTEND.** Quellenarchiv- und Explainability-Muster werden für Claim-IDs erweitert. Jede veröffentlichte Kernbehauptung nennt Quelle, herausgebende Institution, Datum, Passage, Evidenzklasse und gegebenenfalls Gegenquelle.

Externe Dokumente und Community-Eingaben gelten als untrusted input. Ein fehlender Beleg wird als `DATA_GAP`, nie als plausibler Ersatz behandelt.

# CiviCRM Notifications

Keine eigene Benachrichtigungslogik im Portal. Die CiviCRM-/Invitation-Blaupause wird erst nach Datenschutzprüfung, Rollenmodell und Vier-Augen-Freigabe angebunden.

Einladungen dürfen weder auf politische Profile noch auf veröffentlichte Fachvoten rückwirken. Fehlende Freigaben ergeben `DISABLED`, nicht einen stillen Fallback.

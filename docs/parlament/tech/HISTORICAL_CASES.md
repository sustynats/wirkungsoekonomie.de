# Historical Cases

Historische Checks sind `RETROSPECTIVE_CASE`. Die Datenbank trennt den Wissensstand „damals“ (`source date <= decision date`) strikt von nachträglichen Beobachtungen (`source date > decision date`); ein Trigger weist Verstöße ab.

Die heutige Einordnung benennt Zurechenbarkeitsgrenzen. Ein Lernpunkt darf den Materialitätsstandard erst nach redaktioneller Freigabe weiterentwickeln.

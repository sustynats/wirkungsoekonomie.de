# Analytics

**Entscheidung: REUSE (Muster), Kanonisierung offen.** Der Bestand hat zwei Ingest-Wege; vor Launch bestimmt eine Architekturentscheidung eine kanonische, datensparsame Strecke. Das Portal misst keine politischen Profile und speichert keine Antwort-/Fachvotum-Verknüpfungen.

Mindestdaten: Seitentyp, anonymisierter Ereignistyp, Consent, Zeitpunkt und technischer Fehlercode. Redaktionelle und personenbezogene Daten bleiben außerhalb der öffentlichen Analyse.

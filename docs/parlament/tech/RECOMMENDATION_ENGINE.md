# Recommendation Engine

**Entscheidung: BUILD_NEW, deterministisch und nicht LLM-generiert.** Zulässige Kategorien sind: tragfähig, unter Bedingungen, Erprobung, nacharbeiten, derzeit nicht tragfähig und keine belastbare Empfehlung.

Eine Empfehlung ist nur publizierbar, wenn vier Pflichtfelder vollständig sind: 3–5 Gründe, Änderungskriterium, stärkstes Gegenargument und verbleibender politischer Spielraum. CI prüft mit synthetischen Fixtures: gleicher Fall + gleiche Methodik + gleiche Evidenz + andere Partei = identisches WÖk-Ergebnis.

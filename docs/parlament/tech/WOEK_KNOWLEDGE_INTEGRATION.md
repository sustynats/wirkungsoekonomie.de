# WÖk Knowledge Integration

The leading reference hierarchy in [`reference-manifest.yaml`](../../woek-knowledge/reference-manifest.yaml) controls all current rules.  The editorial backend records the method/ruleset version on assessments and decisions; it must also record a reference snapshot before publication.

Current reuse sources:

- SDG/SDG+ v0.3 and MPD mapping
- Master Items v1.3 (621 WÖk IDs) for indicators
- WÖMS/WÖMM registries for method and tool links
- Begriffsleitfaden for displayed definitions
- V3 deterministic topic and red-line patterns for reusable rule structure

No superseded reference can enter an active prompt template, rule or publication package.

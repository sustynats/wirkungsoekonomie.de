# Aggregation and Noncompensation

`calculation_aggregations` ist ein Ledger, keine Summenmaschine. Es hält Inputs,
ausgeschlossene Werte, Ausschlussgründe, Methode, Gewichte samt Quellen und das
Grenz-Gate fest. Ohne autorisierte Gewichtsgrundlage darf nicht aggregiert
werden.

Vor jeder zulässigen Aggregation läuft das Nichtkompensations-Gate. Eine
gestützte Grenzverletzung wird nicht mit positiven Wirkungen in anderen
Bereichen verrechnet. Physische Zustandswirkung und monetäre Folge dürfen
nebeneinander erklärt, aber nicht als zwei unabhängige Wirkungen doppelt gezählt
werden.

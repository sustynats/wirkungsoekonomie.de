# Non-Compensation Gate

No positive finding may cancel a supported severe negative boundary concern.  `boundary_assessments` are separate from domain mapping and use the statuses `NO_BOUNDARY_CONCERN`, `POTENTIAL_BOUNDARY_CONCERN`, `BOUNDARY_REVIEW_REQUIRED` and `BOUNDARY_BREACH_SUPPORTED`.

The last three block a robust recommendation until reviewed.  This carries forward the existing Reverse Merit Order and V3 red-line pattern without pretending that a parliamentary case can be compressed into an average score.

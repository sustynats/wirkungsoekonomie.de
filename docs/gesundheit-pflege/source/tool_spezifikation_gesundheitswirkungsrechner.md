# Tool-Spezifikation: Gesundheitswirkungsrechner und Pflegewirkungscheck

## Zweck
Die Tool-Suite macht Gesundheitswirkung modellhaft sichtbar. Sie ist keine medizinische Diagnose, keine Pflegebegutachtung, keine Rechtsberatung und kein Personen-Scoring. Bewertet werden Programme, Räume, Angebote, Versorgungsketten und Finanzierungsvorschläge.

## Module
1. Gesundheitswirkungsindex GWI
2. Präventionswirkungsrechner
3. Pflegewirkungscheck
4. Sozialraum-Gesundheitsprofil
5. One-Health-Scorecard
6. EHDS-/Gesundheitsdatencheck
7. Gesundheitskassen-/Wirkungsfonds-Simulator

## Eingaben
- Zielraum: Kommune, Quartier, Kasse, Klinikverbund, Pflegequartier, Unternehmen
- Zielgruppe und Ausgangslage
- Interventionen und Investitionen
- Datenqualität: hoch / mittel / niedrig / modellhaft
- Wirkungsdimensionen: körperlich, psychisch, sozial, ökologisch, digital, demokratisch
- Schutzgrenzen und Nicht-Diskriminierung

## Beispielhafte Formel
Gesundheitswirkung = direkte Zustandsverbesserung + verhinderter Schaden + Resilienzgewinn + Teilhabewirkung - Nebenwirkungen - Umsetzungsrisiken.

## Ausgabe
- Wirkungsprofil
- Datenqualitätsampel
- Präventionsdividende (modellhaft)
- politische Anschlussoptionen
- Hinweis auf Dossiers und Buchanker

## Schutz
Kein individuelles Scoring. Keine Krankheitsprognose für Personen. Keine Sanktion. Keine personenbezogene Verarbeitung ohne Rechtsgrundlage, Einwilligung oder Gemeinwohlmandat.

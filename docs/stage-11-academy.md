# Stage 11: Academy Learning Path

## Ziel

Die Akademie wurde als klarer Lernpfad für Wirkungskompetenz ergänzt, ohne bestehende Module, Texte oder Curriculum-Inhalte zu löschen.

## Bestehende Akademie-Struktur

- `akademie.html`: zentrale öffentliche Akademie-Seite mit 7 Studienabschnitten, 28 Modulen, 84 Vorlesungen, Prüfungslogik, Aufbaupfaden und FAQ.
- `akademie/index.html`: bestehende Weiterleitung auf `akademie.html`.
- `fuer/akademie.html`: Zielgruppenseite zu Wirkungskompetenz lernen.
- `woek-akademie-app/`: separate Akademie-App im Workspace.
- `docs/akademie-app-konzept.md`: Konzeptdokument zur Akademie-App.

## Ergänzung

Auf `akademie.html` wurde eine Curriculum-Übersicht mit zehn Lernstufen ergänzt:

1. Grundbegriffe
2. Wirkung / Wirkungspotenzial / Wirkungsrisiko
3. SDGs & SDG+
4. WÖk-IDs / Daten / Standards
5. Scorecards / NWI / Reverse Merit Order
6. T-SROI
7. Wirkungsrückkopplung
8. Medien / Sprache / Demokratie
9. Pilotierung
10. Praxisprojekt

Jede Lernstufe enthält Lernziel, Vorkenntnisse, Dauer, Kernbegriffe, passende Seiten, passende Dokumente, Übung oder Demo und Status.

## Zertifizierungshinweis

Die Akademie markiert die Zertifizierung weiterhin als interne Qualifikationsbezeichnung. Es wird ausdrücklich klargestellt, dass keine staatliche Anerkennung behauptet wird, sofern sie nicht anders belegt ist.

## Nicht-destruktive Umsetzung

Bestehende Module, Prüfungen, Aufbaupfade, FAQ und Akademie-App-Verweise bleiben erhalten. Die neue Übersicht ist eine Orientierungsschicht vor dem bestehenden Detailcurriculum.

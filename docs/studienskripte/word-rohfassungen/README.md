# Word-Rohfassungen

Dieser Ordner enthaelt interne `.docx`-Rohfassungen der Studienskripte fuer Claude.

Die Word-Dateien sind **nicht** die fuehrende Quelle. Fuehrend bleibt der Markdown-Master unter
`content/studienskripte/<slug>.md`.

## Zweck

- Claude kann die Rohfassung in Word/Google Docs, CI/CD, PDF und Reader finalisieren.
- Layout, Typografie, CI-Farben, PDF-Satz und finale Veroeffentlichungsqualitaet liegen bei Claude.
- Codex bleibt fuer Inhalt, Quellen, Struktur, Tabellen, Formeln, Glossar, Mini-Quiz und Rueckfluss verantwortlich.

## Namensregel

`<slug>.docx`, also z. B.:

- `woek-g-v20.docx`
- `woek-g-v21.docx`
- `wirkungsmanagement-v1.docx`
- `wirkungscontrolling-wc-v1.docx`

# Wirkungscheck Bundestag V3 – Instrumentenfluss

## Grundsatz

Die WÖk-Instrumente bleiben erhalten, folgen aber erst auf den abgeschlossenen
Regelreport. Sie verändern die bisherige Diagnose nicht nachträglich.

## Zuordnung

| Fallmerkmal | Erstes Instrument | Zweites Instrument |
| --- | --- | --- |
| Finanzierung oder Förderung | Fördermittel-Rückkopplung | Wirkungshaushalt |
| Daten- oder Beobachtungsengpass | Gesetzliche Wirkungsrückkopplung | Wirkungsdaten und Data Governance |
| Schwere rote Linie oder Zielkonflikt | Nichtkompensationsprinzip | Gesetzliche Wirkungsrückkopplung |
| Produkt-, Preis- oder Marktanreiz | Produktwirkungssteuer | Wirkungsdaten und Data Governance |
| Unklare Umsetzung | Gesetzliche Wirkungsrückkopplung | Wirkungshaushalt |

Es erscheinen höchstens zwei Karten.

## Jede Instrumentenkarte

1. erklärt das Instrument an einer konkreten Situation;
2. nennt Voraussetzungen und Grenzen;
3. behauptet keinen empirisch bewiesenen Erfolg;
4. verlinkt auf die vollständige Erläuterung auf wirkungsoekonomie.de;
5. bietet optional eine Mini-Einschätzung:

> Wäre dieser Ansatz für eine begrenzte Prüfung oder Erprobung grundsätzlich
> interessant?

Antworten: Ja · Eher ja · Teils/teils · Eher nein · Nein · Noch nicht
beurteilbar.

Danach kann optional gefragt werden, welche Voraussetzung besonders wichtig
wäre. Diese Antwort bleibt lokal, wird nicht analytisch als politische Position
gespeichert und verändert den Regelreport nicht.

## Produktwirkungssteuer – sichtbare Erklärung

Zwei Produkte können heute steuerlich gleich behandelt werden, obwohl ihre
Herstellung sehr unterschiedliche Folgen für Klima, Ressourcen,
Arbeitsbedingungen oder Gesundheit verursacht.

Die Wirkungsökonomie prüft deshalb, ob solche nachweisbaren Unterschiede
teilweise in steuerliche Anreize einfließen könnten. Voraussetzung wären
überprüfbare Daten, nachvollziehbare Regeln, Rechtsschutz und ein vertretbarer
Verwaltungsaufwand.

Es werden keine Steuersätze erfunden und keine Wirkungsbehauptung ohne Nachweis
formuliert.

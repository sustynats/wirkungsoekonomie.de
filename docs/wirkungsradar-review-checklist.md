# Debatten-Kompass Review-Checkliste

## 1. Schnellantwort
- Ist der Claim klar?
- Ist die Kurzantwort direkt nutzbar?
- Ist das Kurzurteil maximal 8 Wörter?
- Gibt es "Ein gutes Bild"?
- Verstärkt das gute Bild keinen Mythos?
- Gibt es eine echte bessere Frage?
- Ist FrameShift vorhanden?

## 2. Menschenschutz
- Werden Menschen als Last dargestellt?
- Werden Gruppen pauschalisiert?
- Gibt es Beschämung?
- Gibt es eine menschenwürdige Lösung?

## 3. Sprache
- Klar, ruhig und konkret?
- Keine Fachwortwand?
- Keine WÖk-Dauerwerbung?
- Antwort sprechbar?

## 4. Fakten
- Faktenlage konkret?
- Was fehlt?
- Sind Zahlen aktuell?
- Sind Unsicherheiten sichtbar?
- Sind Quellen geeignet?

## 5. Systemik
- Mindestens 5 Wirkungsdimensionen?
- Folgen erster, zweiter, dritter Ordnung?
- Rückkopplung oder Lock-in?
- Lösung konkret?

## 6. Vertrauen
- TrustBlock?
- Datenstand?
- nächste Prüfung?
- Gegenposition?
- Quellenkarten?

## 7. Links
- Glossarlinks?
- Narrative?
- Ähnliche Karten?
- Lösungen?
- externe Quellen?

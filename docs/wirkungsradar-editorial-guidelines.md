# Redaktionelle Leitlinien Debatten-Kompass

## Grundsatz
Der Debatten-Kompass zeigt zuerst eine brauchbare Antwort und ein gutes Bild. Probleme werden nicht verschwiegen, aber nicht im ersten Bild verstärkt.

## Sprache
Klar, ruhig, konkret, professionell.

## Schnellantwort
- positives Beispiel
- keine Abstracts
- keine Problemstapel
- keine Menschen als Last
- keine WÖk-Dauerwerbung

## Fakten
- immer Quellen
- Datenstand
- Bilanzgrenze
- Unsicherheiten

## Narrative
- benennen, nicht ausmalen
- zeigen, was ausgelöst werden soll
- Frame-Shift anbieten

## Psychologie
- alltagssprachlich
- max. 3 Effekte oben
- keine Copy-Paste-Blöcke

## Quellen
- A/B/C/D-Tiers
- Grenzen jeder Quelle
- Gegenposition sichtbar

## Status
- keine Seite ohne Gate prominent

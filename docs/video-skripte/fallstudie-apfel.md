## Kernaussage (1 Satz)
Das Apfelbeispiel zeigt, warum ein Produkt nicht automatisch gut wirkt, nur weil es regional, bio, billig oder klimaarm erscheint.

## Folien
### Folie 1 - Ein einfacher Apfel
- On-Screen: Ein Produkt / viele Wirkungen / Preis reicht nicht
- Chart/Visual: `assets/img/blog/2026-05-28-warum-billig-oft-teuer-ist-apfel.jpg` oder neutraler Apfel mit Wirkungskarten.
- Substanz fuer Narration: Der Apfel ist didaktisch stark, weil er vertraut ist. Gerade bei einem einfachen Produkt wird sichtbar, dass Wirkung nicht aus einem einzigen Merkmal abgeleitet werden darf.

### Folie 2 - Die falschen Kurzschluesse
- On-Screen: regional = immer gut? / bio = immer gut? / billig = effizient? / Import = immer schlecht?
- Chart/Visual: Vier Mythenkarten mit Fragezeichen.
- Substanz fuer Narration: Wirkungsökonomisch reicht kein Label allein. Regionalitaet, Bio, Preis oder Herkunft koennen wichtige Hinweise sein, ersetzen aber keine Betrachtung von Wasser, Energie, Lagerung, Transport, Arbeit, Boden und Datenqualitaet.

### Folie 3 - Lebenszyklus des Apfels
- On-Screen: Anbau / Wasser / Lagerung / Transport / Handel / Verderb
- Chart/Visual: Lebenszykluspfad "Baum -> Lager -> Transport -> Regal -> Konsum".
- Substanz fuer Narration: Ein Apfel wirkt ueber seinen Lebenszyklus. Ein heimischer Apfel kann durch lange Kuehllagerung Energie benoetigen; ein importierter Apfel kann Transportwirkung haben; entscheidend ist der konkrete Wirkpfad.

### Folie 4 - Scorecard statt Bauchgefuehl
- On-Screen: Klima / Wasser / Boden / Arbeit / Gesundheit / Datenqualitaet
- Chart/Visual: einfache Produktscorecard mit -3 bis +3 und Datenqualitaetsstufe.
- Substanz fuer Narration: Die Produktscorecard buendelt Indikatoren und Datenqualitaet. Sie zeigt nicht nur ein Endurteil, sondern welche Wirkungsfelder belastbar, unklar oder kritisch sind.

### Folie 5 - Reverse Merit Order
- On-Screen: schlechtester kritischer Wert begrenzt / keine Kompensation / rote Linien
- Chart/Visual: `assets/visuals/model/woek_reverse_merit_order_schutzregel.svg`.
- Substanz fuer Narration: Gute Werte in einem Feld duerfen schwere negative Wirkung in einem anderen Feld nicht ausgleichen. Wenn etwa Wasserstress oder Arbeitsbedingungen kritisch sind, muss das sichtbar bleiben, auch wenn andere Werte gut aussehen.

### Folie 6 - Was die Fallstudie zeigt
- On-Screen: Wirkung pruefen / Daten verbessern / Entscheidungen rueckkoppeln / keine Verbraucherbewertung
- Chart/Visual: Prozess "Produktdaten -> Scorecard -> Rueckkopplung -> bessere Alternativen".
- Substanz fuer Narration: Die Apfel-Fallstudie ist kein Steuerbescheid und keine Kaufmoral. Sie zeigt modellhaft, wie Produktwirkung, Datenqualitaet, Scorecard und Rueckkopplung zusammenspielen koennen.

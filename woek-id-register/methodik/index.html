Methodik

Wie aus Daten Wirkungsscores werden

Daten → Messwert → AutoScore → BenchmarkScore → RedLineScore → FinalScore → Rückkopplung.

Bewertungsfluss

Ein Messwert wird zuerst gegen zeilenspezifische Schwellen gelesen. Danach wird er mit einem Benchmark abgeglichen. Rote Linien und Nichtkompensation begrenzen die Aufwertung. Der FinalScore ist eine Forschungslogik, keine amtliche Entscheidung.

Reverse Merit Order

Die schwächste kritische Wirkung begrenzt die Gesamtbewertung. Schwerwiegende negative Wirkung darf nicht durch positive Wirkung an anderer Stelle schön gerechnet werden.

NWI und T-SROI getrennt

NWI ist eine operative Netto-Wirkungskennzahl für konkrete Wirkungseinheiten. T-SROI betrachtet Transformationswirkung und Systemhebel. Beide dürfen nicht vermischt werden.

Datenqualität und Unsicherheit

Datenqualität, Quelle, Systemgrenze, Benchmarkreife und Assurance-Level bleiben sichtbar. Fehlende Daten erzeugen keinen finalen Score.
